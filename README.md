## metadata-GUI
자율주행 데이터 수집 시 주행 환경 및 시나리오 정보를 입력하기 위한 GUI 소프트웨어  
시간대, 기상 조건, 주행 모드, Trigger 원인, 도로 환경 등 수집 데이터의 metadata 정보를 설정  
입력된 metadata 정보를 소켓 통신을 통해 데이터 수집 시스템으로 전달

## 사사
본 연구는 과학기술정보통신부 및 정보통신기획평가원의 자율주행기술개발혁신사업의 지원을 받아 수행된 연구임 (RS-2023-00232046, 비정상 주행 데이터 전송을 통한 클라우드 기반 원인 분석 기술 개발).
